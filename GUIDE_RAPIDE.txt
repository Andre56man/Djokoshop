📋 INSTALLATION RAPIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option 1 - Automatique (Windows):
   Double-cliquez sur: start.bat

Option 2 - Manuelle:
   1. pip install -r requirements.txt
   2. python manage.py migrate
   3. python manage.py create_categories
   4. python manage.py createsuperuser
   5. python manage.py runserver

👥 CRÉATION DE COMPTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CLIENT (visiteur):
   1. Allez sur le site
   2. Cliquez "S'inscrire"
   3. Choisissez "Client"
   4. Ajoutez au panier et commandez

VENDEUR:
   1. Allez sur le site
   2. Cliquez "S'inscrire"
   3. Choisissez "Vendeur"
   4. Publiez vos produits
   5. Gérez vos ventes

ADMINISTRATEUR:
   1. python manage.py createsuperuser
   2. Accédez à /admin/
   3. Gérez toute la plateforme

   EMAIL_HOST_PASSWORD = 'votre-mot-de-passe'
   DEFAULT_FROM_EMAIL = 'votre-email@gmail.com'

Pour Gmail, créez un "mot de passe d'application" dans
vos paramètres de compte Google.

   python manage.py createsuperuser

Créer des catégories:
   python manage.py create_categories

Vider la base de données (CARE!):
   python manage.py flush

Collecter les fichiers statiques:
   python manage.py collectstatic
